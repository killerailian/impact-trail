# Security

This tool reads local files and Git objects. It never intentionally imports or executes inspected Python code. It is not a malware sandbox or a proof that a change is safe.

Do not put credentials or private repositories in public bug reports. Report ordinary issues using a minimal synthetic fixture. A private vulnerability reporting channel should be enabled in repository settings before public launch; until then, do not disclose exploitable private details publicly.

Reports contain relative paths and dependency relationships; inspect them before sharing. No network requests or telemetry are built into the package.
